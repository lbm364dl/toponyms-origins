Política de privacidad

Información sobre los datos técnicos y preferencias que utiliza Nombres de Madrid.

Última actualización: 27 de agosto de 2026.

Datos que recoge el sitio

No hay cuentas de usuario, comentarios ni formularios. El navegador guarda únicamente la preferencia de idioma para recordar la interfaz elegida.

Alojamiento y registros técnicos

El proveedor de alojamiento y la red de distribución pueden tratar direcciones IP, cabeceras y registros técnicos necesarios para entregar y proteger el sitio. Esos registros no se usan aquí para crear perfiles personales.

Mapas y recursos externos

Al abrir el mapa, el navegador puede solicitar recursos a OpenStreetMap, CARTO y el proveedor técnico de la biblioteca cartográfica. Los enlaces a fuentes y mapas externos aplican las políticas de sus respectivos sitios.

Publicidad y analítica

Actualmente no se sirven anuncios ni se instala analítica publicitaria. Antes de activar cualquiera de esos servicios, esta política y el mecanismo de consentimiento se actualizarán.

Consultas

Las consultas sobre privacidad pueden enviarse mediante el canal de contacto del proyecto, sin publicar datos personales sensibles.
