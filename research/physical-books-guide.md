# Book Lookup Guide for Non-Verified Station Entries

**Updated**: 2026-06-06
**Scope**: `content/stations` only. Current station data has 368 entries: 221 `verified`, 144 `probable`, and 3 `uncertain`. Non-verified means `confidence != verified`.

This guide supersedes the broad March 2026 physical-book list. Keep it short: check online and digitized material first, then use physical books only where the station metadata still asks for them. For the full grouped queue of `probable` station reference work, use `research/probable-reference-queue.md`.

## Priority

1. Resolve the 3 `uncertain` entries first: Coslada (`cercanias_036`), Aravaca (`cercanias_061`), and Pitis (`metro_167`).
2. For `probable` entries, use `research/probable-reference-queue.md` first; only consult a book when the station metadata already names that book or when the toponym belongs to the same narrow problem group.
3. Do not re-open broad, already-verified cases unless a station note asks for a specific page or citation.

## Digitized or Online First

| Source | Use for | Access note |
|---|---|---|
| Toponomasticon Hispaniae | First pass for municipality and old place-name entries. Already appears across many current `probable` records. | Online dictionary: <https://toponhisp.org/es/toponhisp/consulta-diccionario/todos> |
| García Sánchez & Nieto Ballester, *Claves en la investigación de la toponimia hispánica* (2024) | Methodology and recent ToponHisp context. Use for standards, not as a station-by-station lookup. | Free IGN digital book: <https://www.ign.es/web/libros-digitales/claves_investigacion_toponimia> |
| Peñasco & Cambronero, *Las calles de Madrid* (1889) | Older Madrid street and square names already cited by a few `probable` records. | Digitized PDF at Memoria de Madrid: <https://www.memoriademadrid.es/view/402083> |
| Capmany, *Origen histórico y etimológico de las calles de Madrid* (1863) | Historical street-name claims, especially when the station source list already cites it. | Digitized record at Biblioteca Digital de la Comunidad de Madrid: <https://bibliotecavirtualmadrid.comunidad.madrid/bvmadrid_publicacion/es/consulta/registro.do?id=87766> |
| Martín Sánchez González, *100 años de la Base Aérea de Getafe 1920-2020* | Getafe Industrial chronology only. | Ministry of Defence PDF edition: <https://publicaciones.defensa.gob.es/100-a-os-de-la-base-aerea-de-getafe-1920-2020-libros-pdf.html> |
| Caridad Arias, "Algunos topónimos madrileños de origen celta" (2004 article) | Aravaca first-pass source; already used by related Aravaca/Carabanchel records. Treat its Celtic Arevaci proposal as a proposal, not settled fact. | Free PDF via Agora/Dialnet: <https://agora.edu.es/descarga/articulo/3012173.pdf> |
| Aparisi Laporta, "La toponimia madrileña: Proceso evolutivo" (1994 article) | Context for the later full Madrid nomenclator. Useful for confirming scope and some historical street/toponym lists, not a substitute for the book. | Free Dialnet PDF: <https://dialnet.unirioja.es/servlet/articulo?codigo=670235> |
| Alonso Fernández-Checa, *Metro de Madrid. ¿Por qué sus estaciones se llaman así?* publisher sample | Quick check for sample entries such as Manoteras, Leganés Central, Lista, and Lucero. It does not cover Pitis. | Free 7-page publisher sample: <https://edicioneslalibreria.com/wp-content/uploads/2023/03/7pag-MetroEstaciones.pdf> |
| Menéndez Pidal, *Toponimia prerrománica hispana* on Google Books | Search-only check for Coslada-related snippets before using a physical copy. | Google Books has snippet/search view but no ebook: <https://books.google.com/books?id=tmYzAAAAMAAJ&q=Coslada> |
| Station-specific local PDFs already in metadata | Coslada, Alcorcón, Los Molinos, Retiro, Moratalaz, Collado Mediano, and similar local cases. | Use each station's `metadata.json` URL before looking for a library copy. |

## Physical Libraries or Purchase

| Source | Use for | Availability note |
|---|---|---|
| Luis Miguel Aparisi Laporta, *Toponimia madrileña: proceso evolutivo* (2001-2005) | Best Madrid-specific physical lookup for Pitis, Valdecarros, Orcasitas, Fuente de la Mora, Valdebebas, Canillejas, and other municipal/toponymic leftovers. | BNE bibliographic record: <https://datos.bne.es/resource/XX3084724>. Not found as an open full-text scan. |
| Aparisi Laporta, Fuencarral-El Pardo focused toponymy/iconography work | Pitis and Fuencarral-El Pardo microtoponyms. | Verify the exact catalogue title before visiting; the old notes cite this as key for Pitis, but no open scan was found. |
| Emilio Nieto Ballester, *Breve diccionario de topónimos españoles* (1997) | Parla, Leganés, Chamartín, Aravaca, Manoteras, Móstoles, and other older Spanish place names. | Open Library has a bibliographic record only: <https://openlibrary.org/books/OL286158M/Breve_diccionario_de_topo%CC%81nimos_espan%CC%83oles>. Use a physical copy for wording and page numbers. |
| Jairo J. García Sánchez, *Atlas toponímico de España* (2007) | Coslada, Getafe/Alcorcón/Valdemoro family, and broader linguistic-stratum checks. | Still commercially listed; no open full-text scan found: <https://www.librerialuces.com/es/libro/atlas-toponimico-de-espana_138759>. |
| María Isabel Gea Ortigas, *Los nombres de las calles de Madrid* and *Diccionario enciclopédico de Madrid* | Street-derived Metro names and the Aravaca "Ara Val Cea" proposal. | Current editions are bookshop/library items, not open scans; Casa del Libro lists the street-name book: <https://www.casadellibro.com/libro-los-nombres-de-las-calles-de-madrid/9788498734362/11395366>. |
| Ramón Menéndez Pidal, *Toponimia prerrománica hispana* | Coslada only, to verify the cited Celtic/flint discussion directly. | Dialnet lists no full text: <https://dialnet.unirioja.es/servlet/libro?codigo=854696>. Google Books has search/snippet view only. |
| Aurelio García López, Carlos Llés Lazo, Óscar Masats, *Coslada* (Lunwerg, 1998) | Coslada only, especially the local flint/quarry explanation. | Physical/secondhand lookup; bibliographic listing: <https://www.todostuslibros.com/libros/coslada_978-84-7782-563-0>. |
| José Felipe Alonso Fernández-Checa, *Metro de Madrid. ¿Por qué sus estaciones se llaman así?* (2023) | Quick cross-check for `probable` Metro entries and Pitis. Do not treat it as the sole authority for deep municipal etymologies. | In print, ISBN 978-84-9873-497-3; publisher/bookshop listings show a 276-page La Librería edition: <https://www.marcialpons.es/libros/metro-de-madrid/9788498734973/>. The free sample is useful but does not include Pitis. |

## Station Checklist

| Station | Look up next |
|---|---|
| Coslada | Menéndez Pidal, *Toponimia prerrománica hispana*; García López et al., *Coslada*; García Sánchez, *Atlas toponímico de España*. Capture exact pages and caveats. |
| Aravaca | Start with the free Caridad Arias article already used by related entries; then Gea Ortigas for the "Ara Val Cea" proposal; Nieto Ballester if it has an Aravaca/Arevaci entry; a critical or facsimile Fuero de Madrid source for the medieval form. |
| Pitis | Alonso Fernández-Checa for the Metro-facing explanation; Aparisi general and Fuencarral-El Pardo material; Fuencarral cadastral/notarial/municipal records if books do not resolve it. |
| Next probable batch | Valdecarros, Orcasitas, Fuente de la Mora, Alcorcón, Getafe, Valdemoro, Parla, Leganés, Chamartín, Manoteras, and Móstoles. Use the named source in each station's metadata before adding new books. |

## Removed from the Active Shortlist

These were in the old guide but are no longer first-pass sources for current non-verified station entries:

- Oliver Asín, *Historia del nombre "Madrid"*.
- Asín Palacios, *Contribución a la toponomástica árabe de España*.
- Galmés de Fuentes, *Los topónimos: sus blasones y trofeos*.
- Menéndez Pidal, *Orígenes del español*.
- Pedro de Répide's street guide.
- Santa Cecilia / Fernández Arroyo medieval Madrid work.
- General Metro history books by Moya, Gómez-Santos, Mohedas/Zamorano, and similar works.

Use them only if a specific station note names them. Otherwise they are too broad, secondary, or unrelated to the current 147 non-verified station records.
